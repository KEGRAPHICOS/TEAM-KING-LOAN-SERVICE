TEAM KING LOAN SERVICE — FRONTEND ONLY

This package contains only the static website frontend. Backend code, Node dependencies,
database configuration, private uploads, and generated PDFs have been excluded.

Changes:
- Loan form submissions open WhatsApp for +233 540 206 528 (233540206528).
- The applicant's typed form details are prefilled into a WhatsApp message.
- Ghana Card upload, selfie upload, Ghana Card number, and signature fields have been removed.
- Loan interest calculation remains client-side at 20%.
- No form data is stored in a backend by this version.

IMPORTANT:
WhatsApp does not send the request automatically. The applicant must review the prefilled
message and press Send in WhatsApp. The frontend cannot attach files or send a message
silently. This static form opens WhatsApp with text only.

GitHub Pages:
1. Extract these files.
2. Upload index.html, homepage.html, index.css, homepage.css, javascript.js, and the Logos
   folder to the root of your GitHub Pages repository.
3. Enable GitHub Pages from the repository settings if it is not already enabled.
